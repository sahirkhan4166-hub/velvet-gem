## Free publishing
Upload this folder to a public GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Editing products
Open `script.js` and edit the `products` array to change product names, categories, prices, images and descriptions.
